# Кирпичество

Учебная 3D-игра на Unity про космический маршрут и сборку компьютера.

## Готовая сборка для ПК

Сборка для Windows находится в папке `Builds/Windows/`.

Для запуска откройте `Builds/Windows/Kirpichestvo.exe`. Не отделяйте EXE от папки сборки: рядом должны оставаться `Kirpichestvo_Data`, `MonoBleedingEdge` и `UnityPlayer.dll`.

## Исходный проект

- Версия Unity: `2022.3.45f1`
- Основная сцена: `Assets/Scenes/SampleScene.unity`
